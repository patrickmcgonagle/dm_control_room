# Local media library

This directory is intentionally empty in the public repository.

DM Control Room creates these folders automatically when the server starts:

- `maps/`
- `scene-art/`
- `music/`
- `ambience/`
- `sound-effects/`
- `tokens/`
- `handouts/`

Only add media that you have the right to use. Local media is ignored by Git by default so personal maps, downloaded videos, music, character art, and handouts are not accidentally redistributed.
